# Networking — sample notes

## What does TCP guarantee?
Ordered, reliable delivery — lost segments are retransmitted and duplicates are dropped.

## What does UDP trade away for speed?
Reliability and ordering; the application handles retransmission or ordering if it needs them.

## What is the difference between a switch and a router?
A switch forwards frames within one local network using MAC addresses; a router forwards packets between networks using IP addresses.
